# Security Policy

## Reporting a Security Concern

Do not open a public issue for a suspected vulnerability or sensitive security concern.

Email [hello@forgedita.com](mailto:hello@forgedita.com) with:

- a concise description of the concern
- the affected document, interface, or component
- steps to reproduce when applicable
- potential impact
- any suggested mitigation

ForgeDITA will acknowledge the report and coordinate disclosure after the concern is understood.

## Current Boundary

This public repository contains architecture documents and illustrative examples. It does not contain the private product implementation or production credentials.

The target security model is documented in [Security Architecture](docs/architecture/security-architecture.md). Publication of that model is not a certification or a claim that every target control is already deployed.

Never submit credentials, customer content, access tokens, private endpoints, or other confidential material through a public GitHub issue.
